## 📘 Topics covered

- Descriptive statistics (mean, median, skew, kurtosis)
- Univariate analysis — histograms, boxplots, KDE plots, count plots, pie charts
- Bivariate/multivariate analysis — scatter plots, correlation heatmaps, crosstabs
- Finding which features correlate most strongly with a target variable
